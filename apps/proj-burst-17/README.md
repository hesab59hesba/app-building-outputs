# Mood Day

A small Flutter app for daily mood tracking. It shows a 30-day grid covering
the last 30 days (ending today); tap any day and pick one of five moods. The
header shows how many days are logged, your current streak, and a per-mood
tally. Moods are held in memory for the session (no persistence or network).

## Run

    flutter pub get
    flutter run

Run tests with `flutter test`.
