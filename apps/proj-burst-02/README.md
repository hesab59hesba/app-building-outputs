# Flashcards

A Material 3 Flutter app for self-study: tap a flashcard to flip it and reveal the
answer, then mark yourself Correct or Wrong. Each card keeps its own correct/wrong
tally, progress is shown while you work through the built-in deck, and a summary
screen with per-card tallies appears at the end (with restart).

Run it with:

```
flutter pub get
flutter run
```
