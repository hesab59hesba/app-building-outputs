# Clock

A four-tab clock app built with Flutter and Material 3.
- World Clock: local time plus major cities with day-difference badges.
- Alarms: add, label, toggle, and delete in-memory alarms that ring with a dialog.
- Timer: presets, minute/second steps, progress ring, and a time's-up dialog.
- Stopwatch: start/pause, laps with best/worst splits highlighted, and reset.

Run with `flutter run`; run the smoke test with `flutter test`.
