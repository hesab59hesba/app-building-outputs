# Build Info Probe

A simple Material 3 stopwatch built with Flutter.

Shows a large centisecond-precision elapsed time, a Start / Pause / Reset control
row, and a Lap button that records splits into a scrollable list (newest first).
All state is in-memory; light and dark themes follow the system automatically.

## Run

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
