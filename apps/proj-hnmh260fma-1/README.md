# CarSpot

CarSpot saves where you parked with a single tap and guides you back to your car.

- One tap stores your current GPS position, plus an optional note (level, row, landmark).
- Shows how long you have been parked and, on demand, how far away your car is.
- "Walk me to my car" hands the destination to Google Maps (or Apple Maps on iOS).

Run it with:

    flutter pub get
    flutter run
