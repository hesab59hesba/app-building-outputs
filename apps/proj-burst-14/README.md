# Chess Clock

A two-player tap chess clock built with Flutter (Material 3). Tap your half of the
screen to start your clock and tap it again to hand the move to your opponent;
the app bar lets you pick a time control (1–30 min), pause/resume, swap players,
and reset. When a clock hits zero, the flag falls and the winner is announced.

## Run

```sh
flutter pub get
flutter run
```
